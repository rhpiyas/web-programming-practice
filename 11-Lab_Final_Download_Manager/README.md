# Download Manager

A simple desktop-based Download Manager developed as a **Lab Final Project** for the **Desktop and Web Programming** course.

The application allows users to enter a downloadable file URL, select a destination folder, and download the file while monitoring the download progress through a progress bar.

- **Course:** Desktop and Web Programming
- **Project Type:** Lab Final Project
- **Project Name:** Download Manager
- **Course Teacher:** Khalid Masum Sir
- **Platform:** Desktop Application
- **Technology:** Electron.js, JavaScript, HTML, Node.js

## Features

- Enter a downloadable file URL
- Select a destination folder
- Download files directly to the selected folder
- Real-time download progress
- Display downloaded amount and total file size
- Display download destination
- Simple desktop user interface

## Technologies Used

- Electron.js
- JavaScript
- HTML
- Node.js

## How to Run

First, clone the repository and open the project folder in the terminal.

Install the required dependencies:

    npm install

Then start the application:

    npm start

## How It Works

1. Enter a downloadable file URL.
2. Click the **Download** button.
3. Select the destination folder.
4. The application starts downloading the file.
5. The progress bar updates as the file is downloaded.
